
// Divider Generator IP 模板（在加入除法指令前保持注释状态）。
// 在 Vivado 中将 div_gen_0 配置为 AXI4-Stream 接口，且被除数和除数均为 32 位。
// aclk：IP 核时钟，连接至 CPU 时钟。
// aresetn：低有效同步复位，连接至 resetn。
// s_axis_dividend_tdata[31:0]：被除数，即要被除的数值。
// s_axis_dividend_tvalid：被除数数据有效时置 1。
// s_axis_dividend_tready：IP 核能够接收被除数时置 1。
// s_axis_divisor_tdata[31:0]：除数，即用于执行除法的数值。
// s_axis_divisor_tvalid：除数数据有效时置 1。
// s_axis_divisor_tready：IP 核能够接收除数时置 1。
// m_axis_dout_tdata[31:0]：商的输出；在 m_axis_dout_tvalid 置 1 时有效。
// 若配置为同时输出商和余数，dout 宽度为 64 位：[63:32] 为商，
// [31:0] 为余数。请以 IP 定制窗口中显示的实际端口宽度为准。
// m_axis_dout_tvalid：输出结果有效时置 1；必须利用该信号暂停流水线，
// 或将结果写入寄存器。
//
// div_gen_0 u_div_gen_0 (
//     .aclk                    (clk),
//     .aresetn                 (resetn),
//     .s_axis_dividend_tdata   (alu_src1),
//     .s_axis_dividend_tvalid  (dividend_valid),
//     .s_axis_dividend_tready  (dividend_ready),   o
//     .s_axis_divisor_tdata    (alu_src2),
//     .s_axis_divisor_tvalid   (divisor_valid),
//     .s_axis_divisor_tready   (divisor_ready),    o
//     .m_axis_dout_tdata       (div_result),       o
//     .m_axis_dout_tvalid      (div_result_valid)  o
